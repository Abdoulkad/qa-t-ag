# SFD fictive — Module de connexion (démo)

REQ-001 : L'utilisateur se connecte avec un matricule et un mot de passe.

REQ-002 : L'utilisateur se déconnecte de l'application.

BR-001 : Si les identifiants sont corrects, afficher « Connexion réussie. »

BR-002 : Si les identifiants sont incorrects, afficher « Identifiant ou mot de passe incorrect. »

BR-003 : Après déconnexion, afficher « Vous êtes déconnecté. »
